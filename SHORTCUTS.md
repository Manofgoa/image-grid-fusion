# Keyboard Shortcuts — Image Grid Fusion

Every key and mouse gesture of the app, by where it works. The app shows the same list: <kbd>F1</kbd>, or
**Keyboard shortcuts…** in the **⚙** menu. What each feature does is in the [README](README.md); the
words, in the [Glossary](GLOSSARY.md).

## Anywhere

| Shortcut | Does |
|---|---|
| <kbd>F1</kbd> | Show this list |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Paste files, an image or a text into a cell |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected cell or layer alone — the grid with nothing selected, the selected file with the explorer's tiles focused |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copy the grid, like the Copy button |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the grid, like the Save button |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Clear all, with no confirmation |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Turn the image under the mouse — else the selected one — onto the next quarter turn clockwise: +37° to 90°, 90° to 180° |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | The same, counter-clockwise: +37° to 0°, 0° to -90° |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Go to the file explorer's search box; pressed again there, the next view — the folder view reached that way opening at the base folder |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | In the search box, the previous view — the folder view, at the base folder too |
| <kbd>Space</kbd> | Play / Pause the grid — not in a text field |

In a text field, <kbd>Ctrl</kbd>+<kbd>V</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>Z</kbd>,
<kbd>Ctrl</kbd>+<kbd>Y</kbd>, <kbd>Delete</kbd> and <kbd>Escape</kbd> act on its text.

## Selected Image

| Shortcut | Does |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Move the selected image 1 px in its cell, the preview clicked first |
| <kbd>Ctrl</kbd>+arrow | Move it 10 px |
| <kbd>Shift</kbd>+arrow | Move it ignoring the magnetic stops |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+arrow | Jump to the next stop — the center or an edge |
| <kbd>Delete</kbd> | Remove the selected layer, else the selected cell's image |
| <kbd>Escape</kbd> | Close the layer or background edit view, else deselect |

## Mouse Over the Grid

| Shortcut | Does |
|---|---|
| <kbd>Wheel</kbd> | Zoom the cell under the mouse, around the point under it — 5 % a notch, 25 % above 200 % |
| <kbd>Ctrl</kbd>+<kbd>Wheel</kbd> | Finer zoom — 1 % a notch, 5 % above 200 % |
| <kbd>Shift</kbd> held while dragging an image | Ignore the magnetic stops |
| <kbd>Double-click</kbd> a separator | Put it back where the layout has it |

## Crop and Blur Bars

While the Crop or Blur tab shows its bars on the selected cell.

| Shortcut | Does |
|---|---|
| <kbd>Wheel</kbd> | Grow or shrink the zone 5 % a notch, its ratio kept, around its center |
| <kbd>Ctrl</kbd>+<kbd>Wheel</kbd> | The same, around the point under the mouse |
| <kbd>Alt</kbd>+<kbd>Wheel</kbd> | Zoom the image instead |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Wheel</kbd> | Zoom the image, finer |

## Layers

While the Layers tab is selected.

| Shortcut | Does |
|---|---|
| <kbd>Wheel</kbd> over the selected layer | Grow or shrink it 5 % a notch |
| <kbd>Shift</kbd>+<kbd>Wheel</kbd> over the selected layer | Turn it 5° a notch |
| <kbd>Ctrl</kbd> held while dragging a layer | Leave a copy where it was |
| <kbd>Shift</kbd> held while dragging a layer | Move it freely, its placement guides ignored |
| <kbd>Shift</kbd> held while dragging the round handle | Turn by steps of 15° |
| <kbd>Double-click</kbd> the selected layer | Open its edit view |
| <kbd>Double-click</kbd> outside the layer, in its edit view | Close the edit view |

## Pick and Eyedropper

| Shortcut | Does |
|---|---|
| <kbd>Shift</kbd>+<kbd>Click</kbd>, Pick armed | Add a part to keep — Pick stays armed |
| <kbd>Ctrl</kbd>+<kbd>Click</kbd>, Pick armed | Add a part to leave out — Pick stays armed |
| <kbd>Escape</kbd>, <kbd>Right-click</kbd>, Pick armed | Cancel Pick |
| <kbd>Click</kbd>, eyedropper armed | Take the color under the mouse |
| <kbd>Escape</kbd>, <kbd>Right-click</kbd>, any other key, eyedropper armed | Cancel the eyedropper |

## Options

| Shortcut | Does |
|---|---|
| <kbd>Wheel</kbd> over a slider | One unit a notch |
| <kbd>Ctrl</kbd>+<kbd>Wheel</kbd> over a slider | 5 % a notch, onto the multiples of 5 |
| <kbd>Wheel</kbd> over the Zoom slider | The zoom steps of the wheel over a cell — <kbd>Ctrl</kbd> for the finer ones |
| <kbd>←</kbd> <kbd>→</kbd>, <kbd>PageUp</kbd> <kbd>PageDown</kbd>, <kbd>Home</kbd> <kbd>End</kbd> on a slider | Move it by a small step, a large step, to an end |
| <kbd>↑</kbd> <kbd>↓</kbd> in a Frames field | One frame more or less, carried from field to field |
| <kbd>Ctrl</kbd>+<kbd>↑</kbd> <kbd>Ctrl</kbd>+<kbd>↓</kbd> in a Frames field | 5 frames |
| <kbd>Wheel</kbd> over a Frames field | One frame a notch — 5 with <kbd>Ctrl</kbd> |
| <kbd>Enter</kbd> in a Frames field | Apply the number typed |
| <kbd>Escape</kbd> in a Frames field | Put the value back |
| <kbd>Wheel</kbd> over the layout strip | Scroll the layouts |
| <kbd>Click</kbd> the Grid background's image thumbnail | Choose its image in the file picker |

## File Explorer

While its tiles have the focus.

| Shortcut | Does |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Move between the tiles — up and down a line, across the sections' headers |
| <kbd>PageUp</kbd> <kbd>PageDown</kbd> | Move by a page |
| <kbd>Home</kbd> <kbd>End</kbd> | First / last tile |
| <kbd>Enter</kbd>, <kbd>Double-click</kbd> | Add the file to the grid, or open the folder or the group |
| <kbd>Backspace</kbd>, <kbd>Alt</kbd>+<kbd>↑</kbd> | Go to the parent folder |
| <kbd>F2</kbd> | Rename the selected group, in the People view |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected file |
| <kbd>Ctrl</kbd>+<kbd>Wheel</kbd> | Larger or smaller tiles, 15 % a notch |
| <kbd>Wheel</kbd> | Scroll the list |

## Search Box and URL Zone

| Shortcut | Does |
|---|---|
| <kbd>Enter</kbd> in the search box | Add the first result to the grid |
| <kbd>↓</kbd> in the search box | Go to the first tile |
| <kbd>Alt</kbd>+<kbd>↑</kbd> in the search box | Go to the parent folder |
| <kbd>Escape</kbd> in the search box | Give the focus back to the grid, the search kept |
| <kbd>Enter</kbd> in the URL field | Load the URL |

## Dialogs

| Shortcut | Does |
|---|---|
| <kbd>Enter</kbd> | OK |
| <kbd>Escape</kbd> | Cancel, or close this list or the Component updates window |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>PageUp</kbd> <kbd>PageDown</kbd>, <kbd>Home</kbd> <kbd>End</kbd> in this list | Scroll it |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> in a preset's description | Save the preset — <kbd>Enter</kbd> alone starts a new line |

## Windows

What Windows gives every window and control of the app.

| Shortcut | Does |
|---|---|
| <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous control |
| <kbd>Alt</kbd>+<kbd>F4</kbd> | Close the window — the main one only hides, the app staying in the tray |
| <kbd>Alt</kbd>+<kbd>Space</kbd> | The window's menu: move, size, minimize |
| <kbd>Alt</kbd>+<kbd>↓</kbd> on a drop-down | Open it |
| <kbd>↑</kbd> <kbd>↓</kbd> in a list or a drop-down | Previous / next item |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> in a text field | Select all its text |
| <kbd>Ctrl</kbd>+<kbd>X</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd> in a text field | Cut, copy, paste text |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> in a text field | Undo the typing |
| <kbd>Home</kbd> <kbd>End</kbd>, <kbd>Shift</kbd>+arrow in a text field | Go to its start / end, extend the selection |
