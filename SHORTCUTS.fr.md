# Raccourcis clavier — Image Grid Fusion

Toutes les touches et tous les gestes de souris de l'application, selon l'endroit où ils agissent.
L'application montre la même liste, en anglais : <kbd>F1</kbd>, ou **Keyboard shortcuts…** dans le menu
**⚙**. Ce que fait chaque fonction est dans le [README](README.fr.md) ; les mots, dans le
[Glossaire](GLOSSARY.fr.md).

## Partout

| Raccourci | Effet |
|---|---|
| <kbd>F1</kbd> | Afficher cette liste |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Annuler |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Rétablir |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Coller des fichiers, une image ou un texte dans une cellule |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copier à part la cellule ou le calque sélectionné — la grille sans sélection, le fichier sélectionné quand les tuiles de l'explorateur ont le focus |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copier la grille, comme le bouton Copy |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Enregistrer la grille, comme le bouton Save |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Tout effacer, sans confirmation |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Tourner l'image sous la souris — sinon l'image sélectionnée — jusqu'au quart de tour suivant dans le sens horaire : +37° vers 90°, 90° vers 180° |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | La même chose, dans le sens antihoraire : +37° vers 0°, 0° vers -90° |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Aller dans la zone de recherche de l'explorateur de fichiers ; pressé de nouveau là, la vue suivante — la vue dossiers atteinte ainsi s'ouvrant au dossier de base |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | Dans la zone de recherche, la vue précédente — la vue dossiers, au dossier de base aussi |
| <kbd>Space</kbd> | Lecture / pause de la grille — pas dans un champ de texte |

Dans un champ de texte, <kbd>Ctrl</kbd>+<kbd>V</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>Z</kbd>,
<kbd>Ctrl</kbd>+<kbd>Y</kbd>, <kbd>Delete</kbd> et <kbd>Escape</kbd> agissent sur son texte.

## Image sélectionnée

| Raccourci | Effet |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Déplacer l'image sélectionnée de 1 px dans sa cellule, après un clic sur l'aperçu |
| <kbd>Ctrl</kbd>+flèche | La déplacer de 10 px |
| <kbd>Shift</kbd>+flèche | La déplacer en ignorant les arrêts magnétiques |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+flèche | Sauter à l'arrêt suivant — le centre ou un bord |
| <kbd>Delete</kbd> | Retirer le calque sélectionné, sinon l'image de la cellule sélectionnée |
| <kbd>Escape</kbd> | Fermer la vue d'édition du calque, sinon désélectionner |

## Souris sur la grille

| Raccourci | Effet |
|---|---|
| <kbd>Molette</kbd> | Zoomer la cellule sous la souris, autour du point sous elle — 5 % par cran, 25 % au-delà de 200 % |
| <kbd>Ctrl</kbd>+<kbd>Molette</kbd> | Zoom plus fin — 1 % par cran, 5 % au-delà de 200 % |
| <kbd>Shift</kbd> maintenu en glissant une image | Ignorer les arrêts magnétiques |
| <kbd>Double-clic</kbd> sur un séparateur | Le remettre là où la disposition le place |

## Barres du recadrage et du flou

Tant que l'onglet Crop ou Blur montre ses barres sur la cellule sélectionnée.

| Raccourci | Effet |
|---|---|
| <kbd>Molette</kbd> | Agrandir ou réduire la zone de 5 % par cran, son ratio gardé, autour de son centre |
| <kbd>Ctrl</kbd>+<kbd>Molette</kbd> | La même chose, autour du point sous la souris |
| <kbd>Alt</kbd>+<kbd>Molette</kbd> | Zoomer l'image à la place |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Molette</kbd> | Zoomer l'image, plus finement |

## Calques

Tant que l'onglet Layers est sélectionné.

| Raccourci | Effet |
|---|---|
| <kbd>Molette</kbd> sur le calque sélectionné | L'agrandir ou le réduire de 5 % par cran |
| <kbd>Shift</kbd>+<kbd>Molette</kbd> sur le calque sélectionné | Le tourner de 5° par cran |
| <kbd>Ctrl</kbd> maintenu en glissant un calque | En laisser une copie à sa place |
| <kbd>Shift</kbd> maintenu en glissant un calque | Le déplacer librement, sans ses guides de placement |
| <kbd>Shift</kbd> maintenu en glissant la poignée ronde | Tourner par pas de 15° |
| <kbd>Double-clic</kbd> sur le calque sélectionné | Ouvrir sa vue d'édition |
| <kbd>Double-clic</kbd> hors du calque, dans sa vue d'édition | Fermer la vue d'édition |

## Pick et pipette

| Raccourci | Effet |
|---|---|
| <kbd>Shift</kbd>+<kbd>Clic</kbd>, Pick armé | Ajouter une partie à garder — Pick reste armé |
| <kbd>Ctrl</kbd>+<kbd>Clic</kbd>, Pick armé | Ajouter une partie à laisser de côté — Pick reste armé |
| <kbd>Escape</kbd>, <kbd>Clic droit</kbd>, Pick armé | Annuler Pick |
| <kbd>Clic</kbd>, pipette armée | Prendre la couleur sous la souris |
| <kbd>Escape</kbd>, <kbd>Clic droit</kbd>, toute autre touche, pipette armée | Annuler la pipette |

## Options

| Raccourci | Effet |
|---|---|
| <kbd>Molette</kbd> sur un curseur | Une unité par cran |
| <kbd>Ctrl</kbd>+<kbd>Molette</kbd> sur un curseur | 5 % par cran, sur les multiples de 5 |
| <kbd>Molette</kbd> sur le curseur Zoom | Les pas de zoom de la molette sur une cellule — <kbd>Ctrl</kbd> pour les plus fins |
| <kbd>←</kbd> <kbd>→</kbd>, <kbd>PageUp</kbd> <kbd>PageDown</kbd>, <kbd>Home</kbd> <kbd>End</kbd> sur un curseur | Le déplacer d'un petit pas, d'un grand pas, jusqu'à un bout |
| <kbd>↑</kbd> <kbd>↓</kbd> dans un champ Frames | Une image de plus ou de moins, reportée d'un champ à l'autre |
| <kbd>Ctrl</kbd>+<kbd>↑</kbd> <kbd>Ctrl</kbd>+<kbd>↓</kbd> dans un champ Frames | 5 images |
| <kbd>Molette</kbd> sur un champ Frames | Une image par cran — 5 avec <kbd>Ctrl</kbd> |
| <kbd>Enter</kbd> dans un champ Frames | Appliquer le nombre saisi |
| <kbd>Escape</kbd> dans un champ Frames | Remettre la valeur |
| <kbd>Molette</kbd> sur la bande des dispositions | Faire défiler les dispositions |

## Explorateur de fichiers

Tant que ses tuiles ont le focus.

| Raccourci | Effet |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Passer d'une tuile à l'autre — vers le haut et le bas d'une ligne, par-dessus les en-têtes des sections |
| <kbd>PageUp</kbd> <kbd>PageDown</kbd> | Avancer d'une page |
| <kbd>Home</kbd> <kbd>End</kbd> | Première / dernière tuile |
| <kbd>Enter</kbd>, <kbd>Double-clic</kbd> | Ajouter le fichier à la grille, ou ouvrir le dossier ou le groupe |
| <kbd>Backspace</kbd>, <kbd>Alt</kbd>+<kbd>↑</kbd> | Aller au dossier parent |
| <kbd>F2</kbd> | Renommer le groupe sélectionné, dans la vue Personnes |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copier le fichier sélectionné |
| <kbd>Ctrl</kbd>+<kbd>Molette</kbd> | Tuiles plus grandes ou plus petites, 15 % par cran |
| <kbd>Molette</kbd> | Faire défiler la liste |

## Zone de recherche et zone URL

| Raccourci | Effet |
|---|---|
| <kbd>Enter</kbd> dans la zone de recherche | Ajouter le premier résultat à la grille |
| <kbd>↓</kbd> dans la zone de recherche | Aller à la première tuile |
| <kbd>Alt</kbd>+<kbd>↑</kbd> dans la zone de recherche | Aller au dossier parent |
| <kbd>Escape</kbd> dans la zone de recherche | Rendre le focus à la grille, la recherche gardée |
| <kbd>Enter</kbd> dans le champ URL | Charger l'URL |

## Boîtes de dialogue

| Raccourci | Effet |
|---|---|
| <kbd>Enter</kbd> | OK |
| <kbd>Escape</kbd> | Annuler, ou fermer cette liste ou la fenêtre Component updates |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>PageUp</kbd> <kbd>PageDown</kbd>, <kbd>Home</kbd> <kbd>End</kbd> dans cette liste | La faire défiler |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> dans la description d'un preset | Enregistrer le preset — <kbd>Enter</kbd> seul commence une nouvelle ligne |

## Windows

Ce que Windows donne à chaque fenêtre et contrôle de l'application.

| Raccourci | Effet |
|---|---|
| <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> | Contrôle suivant / précédent |
| <kbd>Alt</kbd>+<kbd>F4</kbd> | Fermer la fenêtre — la principale est seulement masquée, l'application restant dans la zone de notification |
| <kbd>Alt</kbd>+<kbd>Space</kbd> | Le menu de la fenêtre : déplacer, dimensionner, réduire |
| <kbd>Alt</kbd>+<kbd>↓</kbd> sur une liste déroulante | L'ouvrir |
| <kbd>↑</kbd> <kbd>↓</kbd> dans une liste ou une liste déroulante | Élément précédent / suivant |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> dans un champ de texte | Sélectionner tout son texte |
| <kbd>Ctrl</kbd>+<kbd>X</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd> dans un champ de texte | Couper, copier, coller du texte |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> dans un champ de texte | Annuler la saisie |
| <kbd>Home</kbd> <kbd>End</kbd>, <kbd>Shift</kbd>+flèche dans un champ de texte | Aller à son début / sa fin, étendre la sélection |
